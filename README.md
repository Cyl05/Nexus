# Nexus

Nexus is a community-based social media platform which allows users to create and join communities on various topics. Users can interact in each community with other members on topics of interest. 
Users can create posts on topics which other members can interact with using Upvotes/Downvotes and comments.

This project was built with a React.js frontend with Chakra UI as the UI provider. The backend is composed of ExpressJS and the database in use is PostgreSQL.
